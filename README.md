# COS-202-PROJECT E-COMMERCE APP

# Description
This project is a web-based e-commerce platform that enables both customers and business owners to interact on a single platform and also allows users to browse, select, and purchase products across different categories such as electronics, food, and fashion, etc. It is designed to simulate a real world online marketplace by ensuring key functionality while also ensuring it is simple and user friendly.

# Project Objectives
- To design a simple functional e-commerce system.
- To provide a user-friendly interface for customers.
- To understand how online shopping platforms are operated.
- To practice teamwork and collaboration.
- To practice collaboration using Github.
- To create a proper and structured documentation of the entire process.

# Target Users
- Students
- Small business owners
- Online shoppers
- Companies

  # Problem Definition
  Many businesses lack access to a centralized platform where they can easily sell their products to a broad audience. At the same time, many people need a simple,easy and accessible platform. This project helps to address the need for a structured system which provides a unified e-commerce platform which connects both users and buyers and allows users to view products, select and make a complete purchase easily.

  # Proposed Solution
  The solution to the problems stated above is to create an e-commerce platform that:
  -Displays the products in categories
  - Allows users to browse items
  - Allows users to add/remove things from their cart
  - Automatically calculates the total cost of things in the cart
  - Simulates a checkout process.
 # Core Features
  - User registration and login system
  - Product isting and display
  - Product details view
  - Add to cart functionality
  - Remove items from cart
  - Cart total calculation
  - Checkout simulation
  - Wishlisht(Additional/Optional Feature)
  - Product Filtering(Additional/Optional Feature)
 # System Workflow
    -The user visits the e-commerce platform
    -The user logs in or registers
    - The user browses the product categories
    -The user selects a product
    -The user adds the product to thei cart
    -The user reviews their cart content
    -The user proceeds to checkout
    -The system confirms their order
  # Applications used in the project

  - Github for version control and commiting
